## Installation

1. Clone repository and move into it.

    **Windows**

    ```bash
    git clone https://github.com/kev-encode/creative-crafts-project
    cd .\creative-crafts-project\
    ```

2. Run animation.

    **Windows**

    ```bash
    .\run.bat
    ```
